# Не вордли

Русскоязычный клон [DontWordle](https://dontwordle.com). Ежедневная игра — угадай 5-буквенное слово, но **не угадай** загаданное.

**Играть:** [dontwordle.ru](https://dontwordle.ru)

## Как играть

- 5 попыток (6 в сложном режиме) чтобы **не** угадать загаданное слово
- 🟩 Зелёная — буква на правильном месте, **обязана** там стоять в следующих словах
- 🟨 Жёлтая — буква есть, но не здесь, **обязана** быть на другой позиции
- ⬜ Серая — буквы нет, использовать **нельзя**
- Угадал слово → **ВОРДЛНУЛ** (проигрыш)
- Пережил все ходы → **ВЫЖИЛ** (победа)
- Слова кончились раньше срока → **ВЫБЫЛ** (проигрыш)

## Стек

- Vanilla JS (ES modules), без фреймворков
- CSS variables, dark mode, адаптив
- 4194 пятибуквенных русских существительных
